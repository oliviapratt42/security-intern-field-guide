Skill notes

Web security

Builds fluency with HTTP requests, sessions, APIs, authorization checks, and business logic. Maps strongly to AppSec, offensive testing, and secure engineering.

Traffic analysis

Builds fluency with protocols, DNS, TLS, proxies, flows, and log evidence. Maps strongly to Security Operations Center, detection, infrastructure, and incident response work.

Cryptography

Builds precision with encoding, hashing, encryption, signing, keys, certificates, and tokens. Maps to data protection, secrets handling, identity, and compliance evidence.

Access control

Builds fluency with authorization, least privilege, privileged actions, and permission boundaries. Maps to AppSec, cloud IAM, GRC, and audit work.

Reverse engineering

Builds fluency with unfamiliar software behavior and evidence-backed analysis. Maps to threat intelligence, malware triage, detection engineering, and research paths.

Binary exploitation

Builds fluency with memory, program behavior, unsafe input handling, and exploitability. Maps to vulnerability research, red team work, patch prioritization, and compensating controls.

Integrated security

Builds fluency with connecting identity, applications, infrastructure, telemetry, and risk. Maps to realistic scenarios where several teams and controls interact.
